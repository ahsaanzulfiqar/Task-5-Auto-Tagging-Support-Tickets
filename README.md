# Task 5: Auto Tagging Support Tickets Using LLM

## Objective

The objective of this project is to automatically classify and tag customer support tickets into predefined categories using a Large Language Model (LLM).

## Dataset

* Free-text Support Ticket Dataset

## Methodology

* Loaded and explored support ticket text data
* Used HuggingFace Transformer-based zero-shot classification
* Applied prompt engineering techniques
* Generated top 3 probable tags for each support ticket
* Compared zero-shot and few-shot learning concepts

## Technologies Used

* Python
* Pandas
* HuggingFace Transformers
* Matplotlib
* Seaborn

## Model Used

* facebook/bart-large-mnli

## Key Features

* Zero-shot ticket classification
* Few-shot prompt examples
* Multi-class prediction
* Top-3 probable tags generation

## Skills Gained

* Prompt Engineering
* LLM-based Text Classification
* Zero-shot Learning
* Few-shot Learning
* NLP Automation

## Final Results

* Successfully categorized support tickets into multiple categories
* Generated ranked tag predictions
* Demonstrated practical use of LLMs for customer support automation
